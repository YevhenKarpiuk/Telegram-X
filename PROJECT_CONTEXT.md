# Telegram X Recorder

## Цель и результат
Recorder 1.3.0 на Telegram X 0.29.1.1819 опубликован. main, call-recording-dev, call-recording и upgrade/recorder-tgx-1819 содержат проверенный код интеграции 18a774d8. Перенос выполнялся fast-forward без force push. Тег tgxr-v1.3.0 сохранён на 07294c70; последующие изменения касаются документации.

## Реализация
- Сохранены package ka.soft.tgxr, прежняя подпись, формат записей, PCM hooks, режимы записи, пауза, восстановление, воспроизведение и экспорт.
- Upstream c26c0efa; Recorder tgcalls 29e43315, WebRTC 7b03082. Зависимости закреплены в Git.
- Три Release APK: tens для Android 7–9, qrs для Android 10–12, latest для Android 13+; каждый включает ARM32 и ARM64.

## Проверки и ограничения
- Полная сборка прошла; 36 unit tests успешны. Проверены подпись, сертификат, DEX/JNI, ARM-библиотеки и выравнивание 16 KiB. Подробности: docs/TGX_1819_RECORDER_UPGRADE.md.
- Устройства не было: реальные звонки, аудио и обновление с сохранением данных на телефоне не проверены.
- Локальные пользовательские изменения сохранены побайтно на backup-ветках; не сбрасывать их и не включать в коммиты. Ключи, пароли, local.properties, логи и материалы builds/ сохранять локально.

## Очистка публикации и аудит
- По запросу пользователя удалены Debug APK и его .sha256. В релизе остаются три Release APK, три .sha256 и SHA256SUMS.txt. Описание и общий список сумм обновлены.
- Из публичных документов убраны абсолютные пути пользовательского каталога и расположение хранилища подписи. Старые коммиты содержат прежние пути; история не переписывалась.
- Аудит охватывает текущее дерево, новые Git blobs относительно прежней main, опубликованные APK и сравнение с локальными паролями и файлом подписи. Подробные результаты хранятся локально в builds/publication-audit.json.
- В 2482 Git blobs и четырёх APK (включая удалённый Debug) не обнаружены приватный ключ подписи, его пароли и токены. Telegram api_hash из настроек сборки обнаружен внутри APK и совпадает с APK 1.2.0; не считать его скрытым. Firebase client key совпадает с Recorder 1.2.0. Доступ к серверным ограничениям Firebase не проверен.
- GitHub API подтвердил ровно 7 файлов: три Release APK, три .sha256 и SHA256SUMS.txt; Debug отсутствует. Очистка документов переносится обычным push во все четыре опубликованные ветки. Дальнейшие функциональные проверки требуют Android-устройства.
